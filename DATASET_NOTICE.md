# Dataset and licensing notice

This repository currently contains the four CSV files used by the RICHTER notebook under `Dataset/`:

- `train_values.csv`
- `train_labels.csv`
- `test_values.csv`
- `submission_format.csv`

These files originate from the DrivenData competition *Richter's Predictor: Modeling Earthquake Damage*. Their presence in this repository is for the documented project workflow; it is not a representation that the project author owns the underlying dataset or can grant redistribution rights.

Before reusing, mirroring, or redistributing the CSV files, consult the competition page and the applicable data terms. The repository's MIT license covers project-authored code and documentation only, unless a separate notice explicitly states otherwise.

The notebook downloads these files from the repository's `Dataset/` directory. A clean notebook run therefore requires internet access during setup, as well as package installation access if a required library is not already available.
